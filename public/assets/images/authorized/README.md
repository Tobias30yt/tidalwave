# Authorized visual assets

Place only images you own or have permission to use here. Record the rights holder,
permission and any attribution requirements before adding a file to a view.
Use optimized WebP/AVIF/SVG with explicit width and height; lazy-load below-fold images.
No Geometry Dash or Tidal Wave level assets are included. All bundled illustrations are original SVG.
Nginx intentionally prevents visitors from downloading this README.
